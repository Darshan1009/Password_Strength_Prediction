# Password Strength Predictor

A modern, interactive web application that helps you evaluate and improve your password security using machine learning and natural language processing.

---

## 🚀 Features

- **Instant Password Strength Meter:** Get real-time feedback as you type your password.
- **Smart ML Model:** Uses a trained machine learning model to classify passwords as weak, moderate, or strong.
- **Beautiful UI:** Glassmorphism design, vibrant gradients, and responsive layout.
- **Helpful Tips:** Actionable advice for creating stronger, safer passwords.
- **Password Comparison:** See the difference between weak and strong passwords.
- **No Data Stored:** All checks are performed locally; your passwords are never saved or sent anywhere.

---

## 🛠️ Technologies Used

- **Python 3** (Flask for backend)
- **scikit-learn** (Logistic Regression, TF-IDF)
- **Bootstrap 5** (Frontend UI)
- **HTML/CSS/JS** (Interactive frontend)
- **Jupyter Notebook** (Model training and data analysis)

---

## 💡 How It Works

1. Enter a password in the input box.
2. The app instantly analyzes your password using a machine learning model.
3. The strength meter and tips update in real time.
4. Explore the info tabs to learn about password security and best practices.

---

## 🖥️ Getting Started

1. **Clone the repository:**
   ```sh
   git clone https://github.com/yourusername/password-strength-predictor.git
   cd password-strength-predictor
   ```

2. **Install dependencies:**
   ```sh
   pip install -r requirements.txt
   ```

3. **Run the app:**
   ```sh
   python app.py
   ```

4. **Open your browser:**  
   Go to [http://127.0.0.1:5000/](http://127.0.0.1:5000/)
